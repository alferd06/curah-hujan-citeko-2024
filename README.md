## Kesimpulan

Analisis curah hujan harian di Stasiun Citeko, Jawa Barat periode 2024-2026 menunjukkan:

1. **Pola musiman** — Puncak curah hujan terjadi sekitar Januari, 
   terendah sekitar Oktober. Konsisten dengan musim hujan Jawa Barat.

2. **Curah hujan ekstrem** — Threshold ekstrem berada di 49.28mm per hari. 
   Terdapat 37 hari ekstrem dalam 2 tahun, dominan di Desember–Maret.

3. **Anomali** — Ditemukan curah hujan ekstrem di Mei dan Juli yang 
   seharusnya masuk musim kemarau. Perlu investigasi lebih lanjut.

4. **Catatan data** — 62 nilai kosong (8.5%) diimputasi menggunakan 
   interpolasi linear. Hasil analisis perlu diinterpretasikan dengan 
   mempertimbangkan ketidakpastian ini.
